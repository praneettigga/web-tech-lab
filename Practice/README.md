## How to practise

1. Pick a question folder. Read `CHECKLIST.md`.
2. Build it in `index.html` (and `style.css`). Open the file in a browser.
3. Time yourself. Aim for the length of your real exam slot.
4. Tick every checklist item. Test in the browser, including resizing for responsive ones.
5. Compare against the reference solution if one exists.
